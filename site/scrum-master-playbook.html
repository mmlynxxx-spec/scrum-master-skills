How to use a skill in Copilot

STEP 1Find the skill

Use “I need to…” below, or search the list.

STEP 2Click “Copy for Copilot”

Paste it into Copilot Chat as your first message and send it. Copilot reads the skill and asks for your situation.

STEP 3Describe your situation

Team size, dates, what's going wrong. Copilot follows the skill for the rest of that chat. Start a new chat to switch skills.

Using a skill often? Open it and save it as a Copilot prompt file. Then you type /skill-name in Copilot Chat instead of pasting.
